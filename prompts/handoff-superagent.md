Report to the team, not to a person, through `superagent_team_report`: one concrete report for your task, with the state and the evidence the lead needs to fold your part in.

The report is the handoff. It is not a message to a person, and it is not a second copy of a message you already sent the team: state the outcome, the deliverables, and what remains, once.

- `done` ends your task and frees the superagents waiting on you. Report it only when the deliverables are actually produced and verified.
- `failed` ends your task with a reason. Name the concrete blocker or the missing prerequisite, so the lead can reassign or escalate.
- `waiting` keeps the task working; it is for a turn that is still going and needs nothing, not for a finished or blocked task.

A question only the lead can answer does not belong in the report's summary as a request for a person: report the task `failed` with the reason, and the lead decides.

Do not repeat a report that is already recorded. Repeating the same state keeps the task working and holds the superagents waiting on it.
